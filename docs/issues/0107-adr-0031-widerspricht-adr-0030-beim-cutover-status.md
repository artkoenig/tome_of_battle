# ADR 0031 contradicts ADR 0030 on the engine-cutover status

## Intent

Found during the ADR sweep of issue 0105 (out of that issue's bsdata scope):

nichts entschieden (ADR-0030 bleibt darin unberührt)", while ADR 0030's
revision of 2026-07-25 declares the cutover decided. Two accepted ADRs
disagree about the same decision.

Acceptance criteria:

   cutover status.
